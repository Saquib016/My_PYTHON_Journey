# 🐍 My Python Journey: From Basics to Advanced Data Science

Welcome to my Python learning repository! This project tracks my progress as I master Python, moving from basic syntax to object-oriented programming, and ultimately into advanced data analytics using **NumPy**, **Pandas**, **Matplotlib**, and **Seaborn**.

---

## 🗺️ Learning Roadmap

### 📦 1. Core Basics
- [ ] Variables, Data Types, and Operators
- [ ] Conditional Statements (`if`, `elif`, `else`)
- [ ] Loops (`for`, `while`) and Control Flow
- [ ] Functions, Arguments, and Return Values
- [ ] String Manipulation and Formatting

### 📂 2. Intermediate Mastery
- [ ] Data Structures (Lists, Tuples, Dictionaries, Sets)
- [ ] File I/O (Reading/Writing `.txt` and `.csv` files)
- [ ] Exception Handling (`try`, `except`, `finally`)
- [ ] List Comprehensions and Lambda Functions
- [ ] Working with Built-in Modules (`math`, `datetime`, `os`)

### 🏗️ 3. Object-Oriented Programming (OOP)
- [ ] Classes and Objects
- [ ] Attributes and Methods
- [ ] The Four Pillars: Inheritance, Polymorphism, Encapsulation, and Abstraction
- [ ] Dunder Methods (`__init__`, `__str__`, etc.)

### 📊 4. Advanced Data Track
#### 🔢 NumPy (Numerical Python)
- [ ] Creating Arrays, Vectorization, and Broadcasting
- [ ] Indexing, Slicing, and Boolean Masking
- [ ] Mathematical and Statistical Operations

#### 🐼 Pandas (Data Analysis)
- [ ] Series and DataFrames Setup
- [ ] Handling Missing Data and Cleaning Data
- [ ] Grouping, Aggregation, and Merging Datasets

#### 📈 Matplotlib & Seaborn (Data Visualization)
- [ ] Line Plots, Bar Charts, and Histograms (Matplotlib)
- [ ] Customizing Aesthetics, Labels, and Legends
- [ ] Heatmaps, Scatter Plots, and Pairplots (Seaborn)

## 🚀 Quick Start & Installation

To run any of the scripts locally, clone this repository and set up a virtual environment:

### 1. Clone the repo
```bash
git clone https://github.com
cd My_PYTHON_Journey
```

### 2. Set up a virtual environment
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install required libraries
```bash
pip install numpy pandas matplotlib seaborn
```
